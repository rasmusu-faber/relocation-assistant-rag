# Relocation Assistant — RAG with source citations

Live demo of a retrieval-augmented QA assistant that answers questions about
relocating to Poland, grounded in a small document corpus, returning the source
passages behind every answer.

- **Code & docs:** https://github.com/rasmusfaber-ai/relocation-assistant-rag
- Built with FastAPI, Chroma, sentence-transformers, Streamlit.
- Answers are model-generated and **not** legal advice.
